# Phase 1 scope

Build the production foundation and Company Workspace collaboration features.

## In Phase 1

1. System architecture
2. Git repository
3. Monorepo
4. PostgreSQL
5. Prisma
6. NestJS API
7. Next.js web application
8. Authentication foundation
9. Users
10. Roles
11. Permissions
12. Branches
13. Departments
14. Audit logging
15. Company Workspace
16. Employee discussions
17. Direct messaging
18. Department channels
19. Company announcements
20. Meetings
21. Meeting notes / minutes
22. Tasks
23. Notifications
24. Basic document / file sharing

## Not in Phase 1

Accounting, inventory, warehouse, procurement, e-commerce, AI agents, IoT, payroll, CRM, customer portal, Expo / mobile, and other future modules.

## Waves

- **Wave 0:** Environment, Git (local), monorepo, Docker PostgreSQL, NestJS, Next.js, Prisma identity tables
- **Wave 1:** Authentication
- **Wave 2:** RBAC + Workspace shell
- **Wave 3:** Audit usage, notifications, basic files
- **Wave 4:** Discussions, DMs, channels, announcements
- **Wave 5:** Meetings, minutes, tasks
