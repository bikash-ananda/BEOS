# BEOS — Bikash Engineering Operating System

Official product specification (Wave 0).

## Company

- **Name:** Bikash Engineering Pvt. Ltd.
- **Location:** Pokhara, Nepal
- **Established:** 2023 AD
- **Employees:** 50+
- **Branches / offices:** 3
- **Initial operating area:** Nepal
- **Business:** Multidisciplinary engineering and technology

## Product

BEOS is the digital operating system for Bikash Engineering Pvt. Ltd.

## Business domains BEOS must eventually support

- Electrical engineering
- Electronics
- Civil engineering
- Software / IT
- AI / IoT
- Automation / Robotics
- Agriculture engineering
- Wildlife management technology
- Smart farming
- AI assistance / ToT projects
- Agriculture applications
- Market management applications
- Inventory / e-billing
- IoT systems
- E-commerce
- Government contracts
- Maintenance / repair / AMC services

## Long-term platform (not all built now)

Public corporate website, internal employee workspace, CRM, customer portal, project management, inventory, warehouse, procurement, suppliers, quotations, sales orders, invoicing, payments, accounting, HR, payroll, attendance, assets, maintenance, warranty, e-commerce, AI assistant/agents, IoT integration, reports and analytics, mobile field application, offline field operation.

## Architecture (locked)

- Modular monolith (not microservices)
- Web: Next.js + TypeScript
- API: NestJS + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Package manager: pnpm
- Local database: Docker
- Version control: Git; GitHub when approved
- Mobile (Expo): after web/API and first Workspace release are stable
